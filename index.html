01 / CREATIVE PRODUCTION WORKFLOW

From script to final cut.

This is the user-facing pipeline. Each stage produces editable state or a versioned asset for the next stage.

STAGECREATIVE WORK + OUTPUTTECHNICAL WORK
  1. 01

    Script intake

    Paste or import a .txt/.md script. The source remains editable; parsing is explicitly started by the creator.

    OUTPUT · versioned project input
    Input handling + project state

    Browser editor, file import, FastAPI persistence, project revision checks.

  2. 02

    Storyboard & cast

    Parse characters, scenes, shots, and timed beats. Review and edit structure, dialogue, camera, and action before generation.

    OUTPUT · editable storyboard + cast
    Structured AI parsing

    Azure AI Foundry text path, typed schemas, schema conversion, version tracking, targeted downstream invalidation.

  3. 03

    Visual references

    Create or import character portraits and a scene anchor. Import voice reference audio when needed.

    OUTPUT · cast and scene reference versions
    Reference generation + media validation

    GPT Image 2 image adapter, versioned assets, voice import and FFmpeg normalization. Voice generation is not configured.

  4. 04

    Shot first frames

    Generate a shot image using the current scene anchor and required character references.

    OUTPUT · first-frame version per shot
    Reference-conditioned image pipeline

    Dependency checks, image adapter, source-version lineage, immutable asset publication.

  5. 05

    Motion generation

    Turn a selected first frame and timed shot beats into an H3 video clip. Imported voice references can inform the shot.

    OUTPUT · H3 video version
    Remote GPU orchestration

    Vast GPU provider, ComfyUI H3 adapter, shot-duration validation, remote execution and result transfer.

  6. 06

    Optional enhancement

    Enhance the current H3 clip, or keep the original. The creator can compare versions before final selection.

    OUTPUT · optional enhanced version
    Video enhancement

    SeedVR2 through a separate remote GPU adapter; source-video lineage remains attached.

  7. 07

    Edit & export

    Select an exact H3 or enhanced version for each shot, optionally trim it, preview the sequence, and export.

    OUTPUT · final MP4 in storyboard order
    Deterministic composition

    Version selection, trim derivatives, FFmpeg normalization and concatenation. Unselected shots are omitted.

Shared production ruleAI stages submit durable jobs; every successful output is verified and attached to the input version that produced it.

03 / JOB LIFECYCLE

What happens when a creator generates a shot?

Every AI stage above enters this control path. Select a step to inspect the state transition. This is an illustrative trace, not a live job.

STEP 01 · API CONTROL PLANE

Accept a durable request

The API checks identity, workspace membership, billable-action permission, and the project revision. It writes an idempotent job with a pinned input snapshot, then responds with a durable job ID.

04 / AZURE FOOTPRINT

What Azure does in this system.

The cloud services have distinct jobs. The system keeps application state separate from generated bytes and external inference.

A / RUNTIME

Container Apps

Runs the FastAPI service and generation worker as separate processes. Both deploy from an immutable image digest in a private Container Registry.

B / STATE

PostgreSQL Flexible Server

Stores workspace authorization, editable project state, durable jobs, attempts, asset versions, and audit events. It is also the current job queue.

C / MEDIA

Private Blob Storage

Holds generated media bytes. Application authorization precedes delivery; object provenance is checked before a new version is published.

D / IDENTITY

Entra ID + managed identities

Entra validates users. Separate API and worker identities limit access to Blob, Registry, Foundry, and individual Key Vault secrets.

E / MODELS

Azure AI Foundry

Provides the documented cloud path for structured text parsing. Image and GPU media generation are still handled through separate provider adapters.

F / OPERATIONS

Key Vault + Log Analytics

Key Vault holds runtime secrets. Request correlation, job attempts, outcome and timing summaries, and platform logs support investigation.
